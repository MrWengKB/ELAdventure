    📋 Question set format

    A question set is a CSV file with one question per row and 5 columns separated by commas ,:

    ColumnContent
    QuestionThe question
    AnswerThe correct answer
    Distractor1A wrong option
    Distractor2A wrong option
    Distractor3A wrong option

    Example:

    Question,Answer,Distractor1,Distractor2,Distractor3
What is the capital of France?,Paris,London,Rome,Berlin
How many months are in a year?,12,10,11,13
    • You can keep the header row; it is skipped when importing
    • The four options are shuffled in the game
    • If a cell contains a comma, wrap the whole cell in double quotes, e.g. "1,2,3"
    • You can edit it in Excel, Google Sheets or WPS and then save as CSV; UTF-8 and GBK encodings both work
    • The imported set replaces the current one from the next question on; reloading the page restores the default set
